# MycoGrow: Standalone Fungal Radial Growth Analysis

**MycoGrow** is a free, open-source, serverless, single-page HTML5 application designed for mycologists, plant pathologists, and microbiologists. It provides a complete digital pipeline for fungal radial growth analysis, objective phenotyping, and comparative statistics—all running entirely within the user's web browser without requiring internet access or backend servers.

## Features

- **Digital Caliper**: Precise image-based measurement of fungal colonies.
- **Automated Statistics**: Built-in Ordinary Least Squares (OLS) linear regression to calculate radial growth velocity ($K_r$) directly from daily measurements.
- **Colorimetry Engine**: Objective colony phenotyping by extracting HEX and RGB color values directly from culture images.
- **Daily Log & Notebook**: Systematic documentation of morphological changes and experimental notes.
- **CFU Calculator**: Integrated tool for colony-forming unit calculations.
- **Automated Reporting**: One-click generation of formatted PDF reports containing raw data, regression charts, and extracted phenotypes.
- **Offline First**: Runs completely offline. Data is saved locally in your browser's `localStorage`.

## Usage

1. Download or clone this repository.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Edge, Safari).
3. Start creating experiments and recording your growth data!
